# Tài liệu project

- planning/: bản Excel đã chốt và bảng tra 63 task WBS.
- team-guides/: hướng dẫn thư mục/tích hợp, hướng dẫn GitHub chung và bảy hướng dẫn cá nhân.
- requirements/: user stories và AC từng mô đun, chốt đầu tuần 10.
- architecture/: system.md, erd.md, ticket-state-machine.md, ticket-event.md và quyết định đã thống nhất.
- api/: hợp đồng API chính khi các chủ API thống nhất với An.
- design/patient và design/staff: wireframe của Đạt/Trung.
- modules/: cách dùng/chạy/test mỗi phần, xem README trong thư mục này.
- testing/: cases, evidence, load-report.md và final-report.md.
- sprints/: An tổng hợp planning/review/retro và việc chưa xong.
- demo/: patient-guide.md, staff-guide.md, demo-script.md, release-checklist.md theo bản chạy.

Tạo nội dung theo task; không tạo tài liệu giả như đã hoàn thành. Một bản hợp đồng API chính, một schema và một bản nguồn cho mỗi phiên bản demo. Tài liệu kế hoạch là nguồn tham chiếu, sản phẩm thực tế được nghiệm thu bằng AC và bằng chứng.
