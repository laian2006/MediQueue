## Cách chạy

Chạy API và Vite theo README với database phát triển thử riêng. Cài Playwright cho môi trường kiểm thử theo cách đang dùng của nhóm. Từ gốc repo chạy các bộ dưới đây; mỗi bộ bắt đầu với một DB thử mới vì dữ liệu cuối của bộ trước được giữ lại.

```bash
MEDIQUEUE_E2E_URL=http://localhost:5173 node --test tests/e2e/session-flow.spec.js
MEDIQUEUE_E2E_URL=http://localhost:5173 node --test tests/e2e/staff-flow.spec.js
MEDIQUEUE_E2E_URL=http://localhost:5173 node --test tests/e2e/patient-flow.spec.js
```

Session-flow cần `playwright` có thể được Node phân giải; có thể dùng cài đặt bên ngoài repo qua `NODE_PATH`. `MEDIQUEUE_E2E_CHROMIUM` trỏ tới Chromium tùy chọn. `MEDIQUEUE_E2E_EVIDENCE` là thư mục lưu ảnh của bộ session. Không đưa dependency hoặc mật khẩu DB vào mã nguồn.

## Các tình huống E2E phiên

1. Mở phiên qua SessionPanel, cửa sổ nhân viên thứ hai tự thấy OPEN. Ngừng rồi đóng phiên trống; cửa sổ kia tự trở về trạng thái mở phiên mới.
2. Phiên mới có id mới, bộ đếm 0. Hai phiếu được cấp qua API thật và hiện ở cả hai cửa sổ.
3. Bấm đúp ngừng chỉ gửi một POST. STOPPED chặn cấp mới và giữ các phiếu cũ trong hàng chờ.
4. Đóng còn phiếu bị từ chối và hiển thị lý do. Hủy hai phiếu bằng API thật rồi đóng thành công; cửa sổ kia xóa hàng chờ cũ.
5. Máy chủ đã thực hiện stop nhưng trình duyệt nhận 503 mô phỏng mất phản hồi. Giao diện báo chưa xác nhận, đọc lại thấy STOPPED và cho thao tác đóng; không báo thành công từ phản hồi lỗi.
6. Ở 360 px không tràn ngang, các nút ngừng/đóng/tải lại thao tác được.
