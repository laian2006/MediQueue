# Kiểm thử luồng lấy số và xem phiếu 1.14

Ngày chạy lại 13/11/2026. Kiểm thử nhánh `task/1.14` (mã tại `8127537`)
sau khi ghép `main` tại `fbbcf79`, bản đã có API phiếu từ PR #11.

## Chạy lại

1. Theo [README](../../../README.md) để tạo PostgreSQL thử mới, chạy migration
   001–004, seed và khởi động cả API lẫn Vite. Server phải có router phiếu của
   1.8. CSDL dùng ba tài khoản seed và chưa có phiên đăng ký. Ca thử sẽ mở
   một phiên và ghi ba phiếu.
2. Từ thư mục gốc, dùng Playwright cho ca trình duyệt với trình chạy `node:test`.
   Có thể trỏ `MEDIQUEUE_E2E_CHROMIUM` tới Chrome hoặc Chromium đã cài.

```sh
npm install --no-save --no-package-lock playwright
npx playwright install chromium
```

```powershell
$env:MEDIQUEUE_E2E_URL = 'http://localhost:5173'
node --test tests/e2e/patient-flow.spec.js
```
