# Tài liệu mô đun

Tạo và cập nhật các tệp sau trong task chung 8 giờ/sprint; không thêm một vòng giờ riêng:

- sessions.md — An: mô đun phiên.
- auth.md — Hưng: xác thực và quyền hồ sơ.
- tickets.md — Đức Anh: cấp/đọc/requestId.
- queue.md — Hoàng Anh: FIFO và tiếp nhận.
- patient.md — Đạt: UI người bệnh và API hủy.
- staff.md — Trung: UI quầy.
- platform.md — Trực: khung, nhật ký, bảng công khai và môi trường chạy.

Mỗi tệp ghi phạm vi, tệp chính, dữ liệu/API dùng, cách chạy/test, trường hợp lỗi và liên kết bằng chứng. Tài liệu cập nhật theo main, không tạo final1/final2 hoặc sao chép mã nguồn vào docs.
